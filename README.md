# 🏏 Global Cricket Analytics Dashboard

End-to-end data analytics project using Excel/WPS to clean, model, and visualize international cricket match data (2014–2026). Built interactive dashboards with pivot tables, slicers, and KPIs to uncover trends in team performance, venues, and seasons.

## 📸 Dashboard Preview
![Dashboard](screenshots/dashboard_preview.png)


## 📊 Key Insights
- Matches by season (trend analysis)
- Team-wise wins comparison
- Venue-wise match distribution
- Interactive filters by year and tournament

## 🛠 Tools & Skills
- Excel / WPS Office  
- Data Cleaning & Transformation  
- Pivot Tables & Charts  
- Dashboard Design (Slicers, KPIs)

## 📁 How to Use
1. Download `Global_Cricket_Analysis.xlsx`  
2. Open in Excel/WPS  
3. Use slicers to filter by year and tournament

## 📌 What I Learned
- Structuring raw data for analysis  
- Building interactive dashboards in Excel  
- Using slicers for dynamic filtering  
- Designing charts for business insights
